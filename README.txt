Zakaria Dou - portfolio website (English + Arabic)

How to host
1. Upload the whole folder (index.html and the img folder) to any static host:
   GitHub Pages, Netlify, Cloudflare Pages, Vercel, or your own web hosting (put the files in public_html).
2. Keep index.html and img/ side by side. No build step, no database.
3. To test on your computer, double-click index.html.

To edit
- Text and project copy: open index.html and search for the text. Project data is in the PROJECTS array inside the script.
- Fonts load from Google Fonts, so the site needs an internet connection to show them as designed.
